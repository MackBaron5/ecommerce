# E-commerce Project

Проект базового ядра для интернет-магазина с использованием ООП на Python.

## Описание текущего репозитория / Функционал:
- **Класс `Product`**: управляет свойствами товара (название, описание, цена, количество). 
  - Реализована инкапсуляция для атрибута цены (`__price`).
  - Добавлен валидирующий сеттер, запрещающий установку нулевой или отрицательной цены.
  - Реализован класс-метод `new_product` для фабрикации объектов из словарей.
- **Класс `Category`**: объединяет товары в группы.
  - Список товаров скрыт в приватный атрибут (`__products`).
  - Добавлен метод `add_product` для безопасного добавления элементов.
  - Геттер `products` возвращает красивый отформатированный список товаров в виде строки.
  - Реализован автоматический подсчет общего количества категорий и уникальных товаров.
- **Добавлен магический метод `__str__` для вывода названия категории и общего количества всех единиц товаров на складе.**

## Нововведения (Домашнее задание 16.1)

- **Наследование классов**: Созданы новые специализированные классы-наследники `Smartphone` (Смартфоны) и `LawnGrass` (Газонная трава), расширяющие базовый класс `Product`.
- **Контроль типов при сложении**: Переработан магический метод `__add__` — теперь складывать общую стоимость на складе можно строго только для товаров одного и того же класса. При попытке сложить разные типы товаров вызывается ошибка `TypeError`.
- **Валидация при добавлении в категорию**: В метод `add_product` класса `Category` внедрена проверка `isinstance()`. Она гарантирует, что в список товаров можно добавить исключительно объекты класса `Product` или его официальных наследников. Попытка добавить некорректные типы данных блокируется вызовом `TypeError`.
